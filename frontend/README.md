# Ibtikar Tech landing

Public landing page for the **Ibtikar Tech** training program (Engineering Management, Scientific Research & Data Analysis, AI & Chatbot Development).

## Scripts

```bash
npm install
npm run dev      # http://localhost:5925
npm run build
npm run deploy   # Cloudflare Worker + tech.ibtikar.tr
```

Live: [tech.ibtikar.tr](https://tech.ibtikar.tr)

Languages: Arabic (default), English, Turkish. Copy lives in `src/i18n/dictionaries`.
